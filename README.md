Windows 11 IT Support & Troubleshooting Lab

Project Overview:
This project simulates common entry-level IT support and help desk tasks in a Windows 11 environment.

Skills Practiced:
- Windows diagnostics
- User account management
- Password resets
- Software installation and removal
- Performance troubleshooting
- Driver and device troubleshooting
- Network troubleshooting
- Disk and storage checks
- PowerShell
- Help desk ticket documentation

Tools Used:
- Windows 11
- Command Prompt
- PowerShell
- Task Manager
- Device Manager
- Disk Management
- Resource Monitor
- winget

Project Goal:
To gain hands-on experience with common tasks performed by entry-level IT support and help desk technicians.
